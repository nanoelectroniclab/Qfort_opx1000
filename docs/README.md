# Project Documentation

Project knowledge is organized by purpose:

- [`spec/`](spec/) contains requirements, experiment plans, and acceptance criteria.
- [`manual/`](manual/) contains operating procedures, setup instructions, and runbooks.
- [`reference/`](reference/) contains concise technical notes and indexed authoritative sources.

Keep human-authored Markdown and small, redistributable supporting files in Git. Store secrets, measurement data, proprietary documents, and large binaries outside the repository.
